# 📄 文档一：纯净漫画阅读器 需求规格说明书 V1.0 (个人版)

| 项目 | 内容 |
| :--- | :--- |
| **项目名称** | 纯净漫画阅读器 (Pure Comic Reader) |
| **版本** | V1.0 (个人自用版) |
| **定位** | **基于 Rust 图像引擎的纯本地离线漫画阅读器** |
| **开发者** | 个人自用 (Single Developer & User) |
| **核心原则** | 解码极速 · 内存安全 · 隐私绝对 · 拒绝在线 |

---

## 1. 核心目标 (The Why)

| 痛点 | 解决方案 | 优先级 |
| :--- | :--- | :--- |
| **大图加载卡** | **Rust 并行解码 + 预加载**，翻页无等待 | **P0 (核心)** |
| **内存爆炸** | **智能缓存策略**，大文件不闪退 (≤300MB) | **P0 (核心)** |
| **图片顺序乱** | **智能排序算法**，自动识别 01/02/03 或 1/2/3 | **P0 (核心)** |
| **广告/联网多** | **纯本地运行**，无广告 SDK，无后台 | **P0 (底线)** |
| **阅读模式少** | 支持单页/双页/垂直/RTL (日漫) | **P1 (体验)** |
| **多设备断档** | **WebDAV 可选同步**，仅同步进度/收藏 | **P1 (Utility)** |

---

## 2. 功能范围 (The What)

### 2.1 核心图像引擎 (Rust 实现)
| 功能 | 需求细节 | 验收标准 |
| :--- | :--- | :--- |
| **格式支持** | CBZ (ZIP), CBR (RAR), PDF, EPUB (图片类) | 常见压缩格式秒开，PDF 渲染清晰 |
| **图像解码** | 并行解码 (Rayon)，支持 JPEG/PNG/WebP | 4K 图片解码≤100ms，CPU 占用低 |
| **智能排序** | 自然排序 (1, 2, 10 而非 1, 10, 2)，识别封面 | 章节内图片顺序正确，无需手动调整 |
| **缩略图生成** | 后台生成封面/缩略图，缓存至本地 | 书架加载流畅，无占位图闪烁 |
| **内存管理** | LRU 缓存策略，自动回收不可见图片内存 | 连续翻页 50 页，内存稳定不增长 |

### 2.2 用户界面 (Flutter 实现)
| 功能 | 需求细节 | 验收标准 |
| :--- | :--- | :--- |
| **书架** | 封面墙展示，支持分类/标签/收藏 | 加载 1000 本漫画无卡顿 |
| **阅读页** | 支持单页/双页/垂直滚动/RTL 模式 | 手势流畅，双击放大，捏合缩放 |
| **进度记忆** | 精确到「第几章第几页」，退出自动保存 | 重启 APP 回到上次阅读位置 |
| **适配** | 手机/平板自适应，平板支持双页跨屏 | 横竖屏切换正常，刘海屏适配 |

### 2.3 数据与同步
| 功能 | 需求细节 | 验收标准 |
| :--- | :--- | :--- |
| **本地存储** | 所有数据存私有目录，缩略图可清理 | 卸载可清除，无外部残留 |
| **WebDAV** | 可选配置，同步进度/收藏/标签 (小文件) | 不同设备进度同步一致 |
| **隐私** | 无后台进程，无多余权限，无数据上报 | 抓包无异常请求，权限仅存储/网络 (可选) |

---

## 3. 不做列表 (The No-Go List)

> **为了聚焦核心，以下功能明确不做：**

- ❌ **在线漫画源**：只读本地文件，不爬取网站。
- ❌ **用户社区/评论**：自用工具，无需社交。
- ❌ **自动更新/推送**：需要时手动编译安装。
- ❌ **复杂特效**：翻页动画简单直接，不追求花哨。
- ❌ **付费/订阅**：完全免费，无内购。
- ❌ **应用商店上架**：直接安装 APK。

## 4. 性能指标 (The Benchmarks)

| 指标 | 目标值 | 测试环境 |
| :--- | :--- | :--- |
| **书架加载** | 1000 本漫画 ≤ 2s | Redmi K40 (Android 12) |
| **翻页响应** | ≤ 100ms (预加载完成) | 同上 |
| **图片解码** | 4K 图片 ≤ 100ms (Rust 并行) | 同上 |
| **内存占用** | ≤ 300MB (大文件阅读) | 同上 |
| **缩略图生成** | 后台异步，不阻塞 UI | 导入后稍等即显示 |
| **冷启动** | ≤ 2.0s | 同上 |

---

## 5. 错误处理原则

- **用户友好**：「文件损坏」而非「Decode Error 503」。
- **容错性强**：压缩包内个别图片损坏，跳过并提示，不崩溃。
- **本地优先**：同步失败不影响本地阅读。
