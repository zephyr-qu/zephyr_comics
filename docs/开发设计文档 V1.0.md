## 2. 核心模块设计

### 2.1 Rust 引擎接口 (FFI)
> **原则**：传递图片像素数据 (Vec<u8>) 而非路径，避免 Flutter 侧重复 IO。

```rust
// native/comic_engine/src/ffi/interface.rs

// 初始化
#[frb(init)]
pub fn init_app();

// 获取漫画文件信息 (章节列表/图片 count)
#[frb(sync)]
pub fn get_comic_info(path: String) -> Result<ComicInfo, AppError>;

// 获取指定页图片数据 (核心接口)
#[frb(async)]
pub async fn get_page_image(
    file_path: String,
    page_index: i32,
    max_width: i32,  // 限制解码尺寸，省内存
    max_height: i32,
) -> Result<ImageData, AppError>;

// 生成缩略图 (用于书架)
#[frb(async)]
pub async fn generate_thumbnail(
    file_path: String,
    size: i32,
) -> Result<Vec<u8>, AppError>;
```

### 2.4 内存缓存策略
> **原则**：防止 OOM (Out Of Memory)。

```rust
// native/comic_engine/src/cache/mod.rs

pub struct ImageCache {
    // LRU 缓存，最大占用 100MB
    cache: LruCache<PageKey, ImageData>,
    max_memory: usize,
    current_memory: usize,
}

impl ImageCache {
    pub fn insert(&mut self, key: PageKey, data: ImageData) {
        // 超出内存限制时，自动淘汰最旧图片
        while self.current_memory > self.max_memory {
            self.remove_oldest();
        }
    }
}
```

## 4. 开发规范 (个人版)

### 4.1 代码风格
- **Rust**: 图像解码必须用 `Rayon` 并行，充分利用多核。
- **Flutter**: 图片展示用 `Image.memory()`，及时 `dispose` 控制器。
- **内存**: Rust 侧严格限制缓存上限，Flutter 侧监听内存警告。

### 4.2 错误处理
- **解码失败**: 返回占位图或错误提示，不崩溃。
- **文件损坏**: 跳过损坏图片，记录日志，继续读取下一张。

### 4.3 性能优化
- **预加载**: 当前页 ±2 页 提前解码至内存。
- **降采样**: 根据屏幕分辨率解码图片，不加载原图 (除非放大)。
- **异步**: 所有解码/解压操作必须异步，不阻塞 UI。

## 7. 验收清单 (发布前自检)

- [ ] **性能**：打开 500MB 漫画文件，翻页无卡顿，内存≤300MB。
- [ ] **排序**：章节内图片顺序正确 (1, 2, 10 而非 1, 10, 2)。
- [ ] **模式**：RTL 模式下，翻页方向正确 (从右向左)。
- [ ] **隐私**：断网能看，无多余权限，无后台。
- [ ] **稳定**：连续翻阅 100 页，不崩溃、不闪退。
- [ ] **同步**：WebDAV 能同步阅读进度。
