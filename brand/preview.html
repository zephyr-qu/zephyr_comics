Zephyr Comics — identity

铜印 · 开书。一坨米金圆印，中间凿出一本摊开的书 —— 印章是"这属于我"， 摊开的书是"在读"。图形不画分格、不画风、不画抽象线：它就说一件事，而且缩到 24px 还认得出。 全套改用浅色系（纸底 + 墨 + 深米金），颜色与字阶仍全部来自 lib/theme/zephyr_theme.dart，没有引入任何新色值或字体资源。

用法

要
  • ✓ 深底用深底文件、浅底用浅底文件 —— 两套是配好对的，别自己换色。
  • ✓ 缩放保持等比；锁定组里图形、细线、间距都由文件给出，不要重排。
  • ✓ 需要单色时用 mark-dark / mark-light，不要给彩色版去饱和。
  • ✓ 小到 24px 优先用方图标，别硬塞横向锁定（字会先糊）。
不要
  • ✗ 拉伸、压扁、旋转，或把圆印换成方印、把书换成对称的两页。
  • ✗ 加阴影、描边、发光、渐变 —— 这枚印是靠"实心圆 + 凿空"的对比立住的。
  • ✗ 在浅底上使用原型那档亮米金（对比不足），或在深底上用深米金（看不见）。
  • ✗ 把书填成米金、圆印填成纸色（正负形一反，读起来就成了一块饼）。

生成物与重新导出

  • android/app/src/main/res/mipmap-<density>/ic_launcher.png（48/72/96/144/192）由 flutter test tool/export_brand_icons.dart 从 brand/logo/icon.svg 重新生成； 两次运行字节一致，且导出前会校验尺寸与采样像素，坏图不会覆盖好图。
  • mipmap-anydpi-v26/ic_launcher.xml 引用 @color/ic_launcher_background（纸色）、 @drawable/ic_launcher_foreground（铜印）、@drawable/ic_launcher_monochrome（书）。
  • test/brand/launcher_icon_test.dart 是漂移守卫：它把四个地方的几何（SVG、导出器、两个 drawable） 锁在一起，并把每个 PNG 与一次实时渲染做像素比对 —— 改品牌文件却忘了同步，flutter test 会先报。
还没做：字标描边成路径（现在依赖系统 serif / monospace）；启动页仍是 Flutter 默认白屏，值得单开一件事。
