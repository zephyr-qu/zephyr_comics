Zephyr Comics — identity

风带 / Wind. 三道收笔的风带斜扫而过，左上厚、右上收成尖 —— 一笔「西风」， Zephyr 就是西风的名字。图形刻意不画书、不画分格：这套身份里，名字承担「风」，字标承担「漫画」。 颜色与字阶全部来自 lib/theme/zephyr_theme.dart，没有引入任何新色值或字体资源。

用法

要
  • ✓ 深底用深底文件、浅底用浅底文件 —— 两套是配好对的，别自己换色。
  • ✓ 缩放保持等比；锁定组里图形与字标的间距、细线长度都由文件给出，不要重排。
  • ✓ 需要单色时用 mark-dark / mark-light，不要给彩色版去饱和。
  • ✓ 小到 24px 时优先用方图标，不要硬塞横向锁定（字会先糊）。
不要
  • ✗ 拉伸、压扁、旋转、切掉风带的收笔尖。
  • ✗ 加阴影、描边、发光、渐变 —— 风带是靠锥形收笔立住的，加效果就散。
  • ✗ 把米金换成其它金色，或用非主题色。
  • ✗ 把图形放进比安全间距更窄的空间。

还没做

  • Android 落地：mipmap-*/ic_launcher.png 与自适应图标两层。注意自适应图标的背景层应当是满幅方图（系统自己做圆角遮罩），现在这枚圆角底板只是展示形态；前景层是风带，压在中间 66%（= 72dp / 108dp 安全区）。本机没有 inkscape / ImageMagick，导出打算用无头 Chrome 或 Flutter 的 dart:ui，都不引外部依赖。
  • 字标描边成路径：现在 ZEPHYR / COMICS 是 <text>，依赖系统字体。
  • 启动画面、关于页里的应用（需要时按现有锁定文件缩放即可）。
